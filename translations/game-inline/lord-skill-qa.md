# Inline LordSkill: перевод, доказательства и границы кандидата

Переведены все 139 уникальных китайских строк из `source/game-coverage/inline-lord-skill-queue.json`. Они встречаются в 1259 точных полях семи ресурсов конфигурации. Приоритет Basic составляет 100 уникальных строк и 176 полей в 61 записи. Число 139 обозначает уникальные строки всех режимов, а не количество вхождений. Пустых значений, пропущенных ID, дубликатов и китайского текста в русских результатах нет.

`lord-skill.ru.json` содержит все 139 пар. `lord-skill.strict.ru.json` содержит 132 пары с исходно корректной разметкой. Оставшиеся 7 пар имеют повреждённое открытие `<b` в самом китайском источнике; для них отдельно подготовлены конечные предложения исправления. Этот участок проверен по проектным исходникам и байтам конфигурации. Загрузка установленной игры, обработчик C#, развёртка динамических параметров и визуальная вёрстка здесь не проверялись.

Сохранены исходные статические excerpts и их SHA в `source/game-inline-evidence/`:

- `lord-skill-consumer-evidence.json`: locator ресурса `8f1b5124739003b6`, исходные строки 67–116 `UICommonTips_Explain3ShowData.lua`, привязки данных и условия вывода.
- `UICommonTips_Explain3ShowData.original-excerpt.lua`: `info.SkillName = self.LordSkillCfg.Name`, `info.SKillDesc = self.LordSkillCfg.Desc`, `info.Slogan = self.LordSkillCfg.WorldViewShort`. Девиз зависит от переключателя `WorldViewShort` и непустого значения.
- `ResLordSkillDataBin.annotations.original-excerpt.lua`: исходные аннотации полей `Name`, `Desc`, `WorldViewShort`, `DynamicDesc` из `display-field-hints.lua`, строки 468–488.
- `lord-skill-source-census.json`: точный подсчёт и список всех 176 Basic source slots с исходным текстом/SHA, подтверждённых в raw PB.

При наличии `PlayerID`, непустых `DynamicDesc` и `SkillDescParams` getter применяет `ConvertLordSkillDescByDynamicParams`; иначе возвращает обычный `Desc`. В этом getter текст поступает непосредственно из конфигурации. Связь wire полей 6/7/21/23 с этими отображаемыми значениями основана на source queue, точном совпадении scalar UTF-8 Basic и аннотациях Lua. Полная проверка схемы C# и активного сценария вывода не выполнена. SHA полного Lua ресурса в evidence является атрибуцией исходного каталога: полный оригинальный Lua файл независимо не читался.

## Текстовые проверки и смысл

У всех 139 пар проверены исходный ID/SHA, порядок и полный набор ID, exact source/target SHA, native contexts, отсутствие пустого результата/CJK, runtime expressions, printf/rich text tokens, последовательность всех арабских цифр, ASCII технические фрагменты и последовательность реальных переводов строк. Сохранены `CR/LF/U+2028/U+2029`, управляющие знаки, native icon markers и исходные символы параметров. Финансовых или иных числовых преобразований в этом участке нет. NBSP, `⁴`, `⁸`, `−` в результатах отсутствуют. Отдельная проверка cmap и реального рендера относится к интеграции.

`scripts/game_lang_codec.py:validate_text` проверил 132 пары по точному исходнику и 7 пар по их отдельно доказанной нормализации повреждённого `<b`. Ошибок нет. Общий codec не менялся. Конечные repairs не ослабляют проверку остальных строк. Автоматический перенос английских подсказок в RU не применялся; китайский текст остаётся источником смысла. Повторяющиеся короткие имена сверены с уже принятым переводом.

Сохранены различия вариантов механик:

- `is-7f5585d0a85b`: действие гексаграммы Basic длится 3 раунда; варианты другого режима с 2 раундами переведены отдельно. `{MingShiYin_1:4}`, `{MingShiYin_2:2}`, `{Energy}`, исходные `-2` и `+1` не заменены числовыми догадками.
- `is-71ad0c3b4062`: усиление `+{ChangeE_Level:2}` и дополнительный `+1` за каждую помощь сохранены.
- `is-4b3d9e272fe6`: начальная атака Сянсян 20; за каждого героя не ниже 10-го уровня, ступени 1–3, атака `+20`. Последовательность исходных цифр сохранена.
- `is-f943914bdc5d`: уровень `+1` за каждые 2 сыгранные карты, максимум `+5` за раунд.
- `is-f12d57d13191`: стоимость `+1` после каждых 3 применений навыка.
- `is-f34f844a36da`: новая игрушечная карта после каждых 2 раундов; другие варианты исходника с 3 раундами не объединены с этой строкой.

## Семь повреждённых открытий rich text

Во всех восьми указанных фрагментах источник имеет `<b` без завершающего `>`, из-за чего китайское содержимое оказывается внутри псевдотега. Предлагается ровно одна вставка `>` на фрагмент, после чего текст переводится обычным образом. Source/target, оба SHA, точные диапазоны и нормализованный source SHA находятся в `lord-skill.markup-repairs.json`. Это 7 уникальных строк / 8 повреждённых открытий / 35 контекстов всех режимов. В Basic это 7 полей.

Оба кандидата сохраняют порядок/тип/tag всех wire полей. Неизменённые 1086/1079 полей записей и все root metadata поля побайтно равны исходнику; числа, IDs, пути, assets, nested/control данные не меняются. Обратная подстановка точных исходных scalar payloads восстанавливает весь оригинальный файл побайтно. Каждое изменение записано в соответствующий `.proof.json` с source/target и raw field SHA, record index, field path, tag и numeric key hints. Независимая финальная проверка прочитала реальные кандидатные bytes и заново подтвердила эти свойства.

`patch_lord_skill_inline.py` читает только project originals. Для каждого из семи допустимых ресурсов требует точный decoded SHA, исходные context slots, фиксированные map/proof/repair SHA и корректные текстовые инварианты. Сам script не извлекает игру и не устанавливает пакет. Финальные проверки также отвергают 11 отрицательных случаев: изменённый pinned SHA, JSON duplicate, неизвестный resource, изменённый repair target/span/операцию, подмену runtime параметра/числа, потерю перевода строки, нарушение порядка rich text и попытку scalar edit числового wire поля.

## Остающиеся вопросы

- `is-77116101afb0` и `is-18015d975767`: источник использует имя 秦律, переведено буквально «Цинь Люй». Текущее имя 嬴律 в main UI — «Ин Люй». Возможно, это старое имя одного персонажа, но без native Lord ID proof два источника не объединены.
- `is-4e93c01020ae`: увеличение качества прогресса задания `+1` сохранено буквально. Внутренняя шкала качества не подтверждена.
- Девизы `元亨利贞。` и `亨小，利贞。` литературно переданы как «Великое свершение. Стойкость во благо.» и «Малое свершение. Стойкость во благо.». Это адаптация игрового текста, а не заявленный официальный русский перевод «И цзин».
- `is-06d96deb38f9`: лишняя закрывающая скобка исходника удалена как обычная пунктуация. Технических выражений/markup в ней нет; описание действия сохранено.
- Отладочные видимые source значения «пусто», «пустой навык», «навык тестовой модели» и placeholder девиза переведены. Их присутствие в source не доказывает доступность на живом экране.
- Root field 1 — 32 ASCII байта `64F05A5E4D365B2A801344BBC5137D61`, field 3 — 1984 байта metadata/index, field 4 — uint `38116559`. Смысл и зависимости от display payload не установлены. Эти поля сохранены, не пересчитаны. Проверенные простые CRC32 вариантов не совпали с field 4. Lossless wire proof не доказывает валидность неизвестного checksum или C# загрузчика.
- Для шести остальных режимов нужны точные project original PB bytes; их перевод и finite contexts готовы, кандидатные bytes пока не строились.
- Весь русский смысл, параметры и числовые условия сохранены, однако естественность длины в реальной подсказке, кегль/переносы и отсутствие перекрытия требуют нативной проверки layout. В этом source-only участке такое подтверждение не заявляется.

Точные пути, размеры и SHA всех артефактов доставки находятся в `lord-skill-delivery-manifest.json`; результат структурных и отрицательных проверок — `lord-skill.validation.json`.
