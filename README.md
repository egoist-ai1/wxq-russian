# WXQ Russian

Неофициальный русификатор Honor of Kings (клиент ACE): тексты игры, картинки интерфейса и по желанию русский лаунчер. Проект не связан с Tencent (см. [NOTICE](NOTICE)).

В репозитории только исходный код, собственный Lua-помощник русификатора, тексты перевода и знак Egoist. Файлов игры, ресурсов и арта Tencent здесь нет.

## Установка

1. Откройте [последний релиз](https://github.com/egoist-ai1/wxq-russian/releases/latest).
2. Скачайте `WXQ-Russian-Setup-<версия>.exe` и запустите. Установщик попросит права администратора.
3. Следуйте окну установщика: он найдёт игру, проверит её версию, сделает резервную копию и поставит перевод. Если игра или лаунчер мешают записи, установщик закроет их перед применением перевода.
4. После установки ярлык «Egoist · Русификатор ACE» открывает менеджер `WXQ-Russian.exe`. Он показывает состояние перевода и позволяет повторить установку, обновить или откатить его.
5. «Удалить перевод» восстанавливает состояние игры до установки и убирает русский лаунчер; менеджер остаётся, а кнопка «Установить снова» возвращает к установке. Полное удаление программы — через настройки приложений Windows.

Установщик пока не имеет подписи издателя, поэтому Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 файла со значением в `update.json` релиза.

> **После обновления игры первый запуск может оставаться на китайском.** Запустите игру один раз до главного меню и закройте её, затем откройте менеджер и повторно установите перевод. Игра должна сначала подготовить актуальный кэш.

Каждый релиз заявляет, с какими версиями игры он работает (`game_versions`). Если игра новее сборки, применяется проверяемая пересадка записей: совпавшие оригиналы переводятся, новые и изменённые остаются штатными. Неподтверждённые данные приводят к отказу до записи. Состав игровых пакетов и русского лаунчера в 0.6.4 сохранён из 0.6.3 для игры 1.6.0.1; новые исправления прежних визуальных дефектов этим релизом не заявляются.

## Как работает обновление в 0.6.4

Один запускаемый менеджер и одно пользовательское окно объединяют установку, откат и обновление. При каждом открытии начинается короткая проверка подписанного манифеста. Она не блокирует установку; сетевой сбой отображается в плашке с возможностью повторить проверку. Если есть новая версия, в этом же окне появляется кнопка обновления.

Скачивание начинается только по кнопке. После проверки подписи, размера и SHA-256 менеджер закрывает старую версию и открывает новую с видимым окном и автоматической переустановкой. Путь игры и выбор русского лаунчера передаются новой версии. Перед её запуском подпись и хеш установщика проверяются ещё раз.

Трей, автозапуск и задача планировщика больше не устанавливаются; прежние компоненты убираются при установке 0.6.4. После закрытия менеджера постоянного процесса обновлений нет. При передаче управления кратко используется внутренняя техническая копия помощника без отдельного интерфейса; одно окно не означает буквально один процесс ОС. Для записи в защищённые каталоги используется обычное повышение прав администратора через UAC; служба или брокер с правами SYSTEM не добавляются.

Обновление берётся из GitHub Releases по фиксированным адресам последнего релиза:

- `releases/latest/download/update.json` - манифест;
- `releases/latest/download/update.json.sig` - подпись манифеста (base64).

Манифест (`schema: 1`, `product: "wxq-russian"`) содержит версию в формате `X.Y.Z`, время выпуска, `key_id` подписавшего ключа, список поддерживаемых версий игры, минимальную версию обновлятора, список адресов (`base_urls`), а также имя, размер и SHA-256 установщика и каждого файла пакета.

Клиент:

1. скачивает `update.json` и `update.json.sig`;
2. проверяет подпись над точными байтами `update.json` вшитым публичным ключом;
3. сравнивает версию с запущенным менеджером и установленным переводом, проверяет `min_updater` и защиту от старого манифеста;
4. по кнопке скачивает установщик и сверяет размер и SHA-256 с манифестом;
5. при любом несовпадении ничего не устанавливает.

Релиз становится виден клиентам только когда `update.json` загружен последним, поэтому недозагруженный релиз не обновляет никого.

Переустановка проверяет подготовленный кэш и сохраняет прежние файлы для отката. Старый маршрут обновления оставлен для перехода с ранее установленных версий; новая установка не создаёт для него задачу и не запускает значок в области уведомлений.

## Безопасность подписи

- Алгоритм: RSA-3072, подпись PKCS#1 v1.5, SHA-256. Совместимо с `RSACryptoServiceProvider.VerifyData(data, "SHA256", signature)` из .NET Framework.
- Ключей два: основной и запасной. Публичные части лежат в `keys/update-public.pem` и `keys/keys.json` вместе с `key_id` (первые 16 hex SHA-256 от DER SubjectPublicKeyInfo). Клиент вшивает оба.
- Закрытые ключи в репозиторий не попадают: они лежат на компьютере автора вне репозитория и защищены паролем, запасной хранится офлайн. Если основной ключ скомпрометирован, выпускается обновление клиента, доверяющее запасному.
- Подпись защищает от подмены манифеста и файлов по сети и на хостинге, но не от компрометации самого ключа.

## Что в репозитории

| Путь | Что это |
|---|---|
| `installer/` | Менеджер перевода: помощник `WXQTool.cs`, активатор русского лаунчера `WXQLauncherRU.cs`, скрипт Inno Setup `WXQRussian.iss`, сборщик `build_installer.py`, окно на WPF (`ui/`), тесты (`tests/`), журнал изменений. Исторический `WXQTray.cs` не входит в состав 0.6.4 |
| `scripts/` | Публикация и подпись релиза (`publish_release.py`, `release_keys.py`), слияние переводов, сборка пакетов для установщика |
| `translations/` | Тексты перевода игры (`game-lang`, `game-inline`) в виде JSON «идентификатор → русский текст», глоссарий, подписи лобби |
| `glossary/` | Решения по канону терминов и имена героев |
| `keys/` | Публичные ключи подписи обновлений |

Не входят в репозиторий: файлы и ресурсы игры, собранные пакеты и установщики, картинки интерфейса и арт Tencent (в том числе фон шапки окна установщика, который при сборке берётся из локальных ресурсов игры), служебные сборки, закрытые ключи. Установщик без этих локальных материалов собирается с плоской шапкой.

## Как собрать

Нужны Windows, Python 3 с пакетами `cryptography` и `Pillow`, .NET Framework (csc) и Inno Setup. Пакеты перевода строятся из локальной копии игры, которой в репозитории нет, поэтому полная сборка установщика возможна только с установленной игрой.

```
python installer/build_installer.py --help
```

Сборка релиза автообновления:

```
python scripts/release_keys.py generate       # один раз: пара ключей и публичные ключи в keys/
python scripts/publish_release.py --check      # поиск утечек в исходниках
python scripts/publish_release.py build --version 1.2.3 --setup <установщик.exe> --install-json <install.json> --payload-dir <папка> --out <папка-вывода> --repo egoist-ai1/wxq-russian
python scripts/publish_release.py verify --manifest <out>/update.json --sig <out>/update.json.sig --dir <out>
```

Для `build` задайте путь к закрытому ключу в переменной окружения `WXQ_RU_SIGNING_KEY`; пароль берётся из `WXQ_RU_SIGNING_PASS` или из `key-pass.txt` рядом с ключом. Сборка сама проверяет подпись публичным ключом и печатает команды `gh release create ... --draft`; они не выполняются автоматически. Порядок: создать черновик, загрузить установщик, затем `update.json.sig`, последним `update.json`, затем `gh release edit --draft=false`.

Тесты подписи: `python -m unittest discover -s scripts/tests_release -t scripts/tests_release -v`.
