# WXQ Russian

Неофициальный русификатор Honor of Kings (клиент ACE): тексты игры, картинки интерфейса и по желанию русский лаунчер. Проект не связан с Tencent (см. [NOTICE](NOTICE)).

В репозитории только исходный код, тексты перевода и знак Egoist. Файлов игры, ресурсов и арта Tencent здесь нет.

## Установка

1. Откройте [последний релиз](https://github.com/egoist-ai1/wxq-russian/releases/latest).
2. Скачайте `WXQ-Russian-Setup-<версия>.exe` и запустите. Установщик попросит права администратора.
3. Закройте игру и лаунчер, следуйте окну установщика: он сам найдёт игру, проверит её версию, сделает резервную копию и поставит перевод.
4. Удаление: кнопка «Удалить перевод» в окне установщика или «Установка и удаление программ». Исходные файлы игры возвращаются из резервной копии.

Установщик пока не имеет подписи издателя, поэтому Windows SmartScreen может показать предупреждение. Сверяйте SHA-256 файла со значением в `update.json` релиза.

> **После выхода обновления игры первый запуск будет на китайском.** Перевод вернётся автоматически после того, как вы один раз запустите игру до главного меню и закроете её. Иначе нельзя — новые хеши файлов игры создаются только самой игрой.

Каждый релиз заявляет, с какими версиями игры он работает (`game_versions`); если игра новее сборки, перевод пересаживается сохранённым установщиком без скачивания.

## Как работает автообновление

Обновление берётся из GitHub Releases по фиксированным адресам последнего релиза:

- `releases/latest/download/update.json` - манифест;
- `releases/latest/download/update.json.sig` - подпись манифеста (base64).

Манифест (`schema: 1`, `product: "wxq-russian"`) содержит версию в формате `X.Y.Z`, время выпуска, `key_id` подписавшего ключа, список поддерживаемых версий игры, минимальную версию обновлятора, список адресов (`base_urls`), а также имя, размер и SHA-256 установщика и каждого файла пакета.

Клиент:

1. скачивает `update.json` и `update.json.sig`;
2. проверяет подпись над точными байтами `update.json` вшитым публичным ключом;
3. сравнивает версию, версию игры и `min_updater`;
4. скачивает файлы и сверяет размер и SHA-256 с манифестом;
5. при любом несовпадении ничего не устанавливает.

Релиз становится виден клиентам только когда `update.json` загружен последним, поэтому недозагруженный релиз не обновляет никого.

Когда игра обновилась, помощник сначала смотрит на неё саму: пока игра не пересоздала свой кэш, он ничего не пишет и показывает «Запустите её один раз до меню и закройте — перевод вернётся сам». После этого перевод возвращается сохранённой копией установщика текущей версии (сеть не нужна); если же вышла новая версия, ставится она. Новая версия не встала - возвращается прежняя. Двойной щелчок по значку в области уведомлений открывает окно состояния (версии перевода и игры, последняя проверка, результат, «Проверить сейчас», «Журнал», «Страница релизов»).

## Безопасность подписи

- Алгоритм: RSA-3072, подпись PKCS#1 v1.5, SHA-256. Совместимо с `RSACryptoServiceProvider.VerifyData(data, "SHA256", signature)` из .NET Framework.
- Ключей два: основной и запасной. Публичные части лежат в `keys/update-public.pem` и `keys/keys.json` вместе с `key_id` (первые 16 hex SHA-256 от DER SubjectPublicKeyInfo). Клиент вшивает оба.
- Закрытые ключи в репозиторий не попадают: они лежат на компьютере автора вне репозитория и защищены паролем, запасной хранится офлайн. Если основной ключ скомпрометирован, выпускается обновление клиента, доверяющее запасному.
- Подпись защищает от подмены манифеста и файлов по сети и на хостинге, но не от компрометации самого ключа.

## Что в репозитории

| Путь | Что это |
|---|---|
| `installer/` | Установщик: помощник `WXQTool.cs`, значок в трее `WXQTray.cs`, активатор русского лаунчера `WXQLauncherRU.cs`, скрипт Inno Setup `WXQRussian.iss`, сборщик `build_installer.py`, окно на WPF (`ui/`), тесты (`tests/`), журнал изменений |
| `scripts/` | Публикация и подпись релиза (`publish_release.py`, `release_keys.py`), слияние переводов, сборка пакетов для установщика |
| `translations/` | Тексты перевода игры (`game-lang`, `game-inline`) в виде JSON «идентификатор → русский текст», глоссарий, подписи лобби |
| `glossary/` | Решения по канону терминов и имена героев |
| `keys/` | Публичные ключи подписи обновлений |

Не входят в репозиторий: файлы и ресурсы игры, собранные пакеты и установщики, картинки интерфейса и арт Tencent (в том числе фон шапки окна установщика, который при сборке берётся из локальных ресурсов игры), служебные сборки, закрытые ключи. Установщик без этих локальных материалов собирается с плоской шапкой.

## Как собрать

Нужны Windows, Python 3 с пакетами `cryptography` и `Pillow`, .NET Framework (csc) и Inno Setup. Пакеты перевода строятся из локальной копии игры, которой в репозитории нет, поэтому полная сборка установщика возможна только с установленной игрой.

```
python installer/build_installer.py --help
```

Сборка релиза автообновления:

```
python scripts/release_keys.py generate       # один раз: пара ключей и публичные ключи в keys/
python scripts/publish_release.py --check      # поиск утечек в исходниках
python scripts/publish_release.py build --version 1.2.3 --setup <установщик.exe> --install-json <install.json> --payload-dir <папка> --out <папка-вывода> --repo egoist-ai1/wxq-russian
python scripts/publish_release.py verify --manifest <out>/update.json --sig <out>/update.json.sig --dir <out>
```

Для `build` задайте путь к закрытому ключу в переменной окружения `WXQ_RU_SIGNING_KEY`; пароль берётся из `WXQ_RU_SIGNING_PASS` или из `key-pass.txt` рядом с ключом. Сборка сама проверяет подпись публичным ключом и печатает команды `gh release create ... --draft`; они не выполняются автоматически. Порядок: создать черновик, загрузить `update.json.sig`, затем `update.json`, затем `gh release edit --draft=false`.

Тесты подписи: `python -m unittest discover -s scripts/tests_release -t scripts/tests_release -v`.
