# Журнал изменений

Подробный журнал установщика по версиям - в [installer/CHANGELOG.md](installer/CHANGELOG.md).

## 0.6.6 — 2026-10-22

- Совместимый перенос строк `.lang`/Global по ключу и SHA исходного текста; новые и изменённые официальные данные сохраняются.
- Чтение больших prime без гигабайтного массива, обработка по ресурсу, очистка проверенных промежуточных файлов и безопасный повтор уборки занятого файла.
- Общие правки заголовков/вкладок, числовых подписей и заголовков помощи событий; заметка о частичной совместимости.
- Независимое ревью Claude, 70 окончательных проверок памяти/уборки и 190 совместимости; все PASS. Реальная игра и ПК друга с Windows 10 не проверены; белые экраны и футер Аллена не объявлены исправленными.

## 0.6.5 — 2026-10-20

- Установка ждёт завершения своего процесса и проверяет код выхода; медленный дисковый обмен учитывается при ожидании. Финальный статус обновления сохраняется при занятом файле статуса.
- Проверка русского лаунчера закрепляет точные данные процесса Windows и допускает задержанную готовность. Профиль, SHA, подпись и принадлежность порта проверяются по-прежнему.
- Пакет 10 v16 добавляет два общих шаблона раскладки заголовков, сохраняя 1914 прежних Lua-ресурсов побайтно. Шрифты и текст не меняются.
- Проверки пройдены; результат на ПК друга с Windows 10, реальная геометрия и китайские футеры остаются непроверенными. Подробности — [installer/CHANGELOG.md](installer/CHANGELOG.md).

## 0.6.4 — 2026-10-20

- Установка, повторная установка, откат и обновление в одном окне менеджера. Трей, автозапуск и задача планировщика убраны с миграцией прежних версий.
- Быстрая проверка обновлений при открытии; загрузка по кнопке с проверкой подписи, размера и SHA-256, перезапуск и автоматическая переустановка.
- После отката менеджер остаётся для следующей установки. Игровые пакеты и лаунчер сохранены из 0.6.3.
- Проверки, состав и ограничения — в [installer/CHANGELOG.md](installer/CHANGELOG.md).

## 0.6.3 — 2026-10-20

- Исправлены установка поверх старых переводов, очистка дополнительных хранилищ и подтверждённых соседних пакетов, неполная установка и пакетный откат.
- Lua v15 сохраняет штатную типографику и переносит целые слова; сокращены подписи характеристик.
- Исправлен поиск русского лаунчера в нестандартных папках; добавлен явный статус подключения.
- Автоматические проверки пройдены; визуальная проверка в игре продолжается. Подробности — [installer/CHANGELOG.md](installer/CHANGELOG.md).

## 0.6.2 — 2026-10-18

- Исправлена раскладка текста в игре: шрифты, размеры, наложения и переносы после 0.6.0/0.6.1. Помощник переноса слов v14 больше не меняет масштаб и режим полей с одним словом, где игра сама масштабирует текст; покрытие экранов прежнее (1914 ресурсов).
- Подробно — [installer/CHANGELOG.md](installer/CHANGELOG.md).

## 0.6.1 — 2026-10-18

- Установщик сам закрывает лаунчер, игру и зависшие процессы, которые мешают установке (включая `王者万象棋.exe`).
- Подробное описание каждого этапа в окне установщика, крупнее шрифт.
- Автообновление: проверка только при заходе в русификатор, без фона; установка по кнопке «Обновить сейчас».
- Подробно — [installer/CHANGELOG.md](installer/CHANGELOG.md).

## 0.6.0 — 2026-10-18

- Первый публичный релиз для игры 1.6.0.1: пять пакетов перевода, русский лаунчер, помощник переноса слов v13 (без диагностического слоя и журнала).
- Публичный репозиторий `egoist-ai1/wxq-russian`: исходный код установщика, скрипты публикации и подписи релиза, тексты перевода и глоссарий.
- Автообновление через GitHub Releases: `update.json` и подпись `update.json.sig` (RSA-3072, SHA-256), два ключа (основной и запасной).
- Экспорт чистого дерева: `scripts/export_repo.py` в рабочем проекте (белый список без ресурсов игры).
- Автообновление после обновления игры: отпечаток игры, пересадка сохранённым установщиком, откат на прежнюю версию, `/UPDATE=1`, кнопка «Выбрать папку игры», окно состояния значка. Ограничение: после выхода обновления игры первый запуск будет на китайском; перевод вернётся автоматически после того, как вы один раз запустите игру до главного меню и закроете её. Иначе нельзя — новые хеши файлов игры создаются только самой игрой.
- Описание релиза: `RELEASE-NOTES.md` (шаблон для `--notes-file`).
