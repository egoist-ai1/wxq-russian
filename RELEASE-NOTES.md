# 0.6.6 — совместимость с обновлениями игры

Известный перевод можно повторно применить после обновления: строки переносятся только при совпадении ключа и исходного текста. Новые и изменённые строки сохраняются в оригинале; неизвестные форматы не угадываются. Официальное обновление может заменить перевод — менеджер предлагает переустановку.

- Большие архивы читаются без загрузки целого гигабайтного файла в память; текстовые ресурсы обрабатываются по одному. На стенде всех 297 карт и 219 601 известных строк пик памяти helper — около 106 МиБ.
- Исправлены общие шаблоны заголовков и вкладок, отображение больших чисел, заголовки помощи событий и пропущенный шаблон выбранной реплики. Длинные числовые подписи выводятся без нового округления.
- Итоговый экран объясняет частичную совместимость. Промежуточные файлы убираются после проверки; занятый временный файл не отменяет проверенную установку.
- Сохраняются резервные копии, проверки SHA и один менеджер без нового трея, службы или постоянного фона. Права администратора — через обычный UAC.

Код прошёл независимое ревью Claude. Финальные стенды: 70 проверок памяти/блокировок/уборки и 190 проверок совместимости, все PASS; Lua — 102 теста, синтаксис 1924/1924, чтение SDK 1927/1927. Новый релиз использует тот же проверенный код, что кандидат 0.6.6-rc1.

Белые области «Зала славы»/«Истории» и причина неприменения футера Аллена на другом ПК остаются открытыми. Настоящий новый патч, геометрия всех экранов и ПК друга с Windows 10 не проверялись. Для Lua и текстур по-прежнему требуется совпадение целого исходного ресурса; уже выпущенные старые EXE без новой metadata не получают новый механизм задним числом.
