# WXQ Russian 0.6.9 — исправление запуска и лаунчера

Для официального патча Honor of Kings ACE 1.7.1 (внутри клиента 1.7.0.1).

- Исправлена кнопка «Запустить игру». Требование прав администратора у официального Tencent-лаунчера теперь обрабатывается штатным UAC; ошибка запуска отображается в менеджере и допускает повтор. Проверки пути, подписи, профиля и файлов сохранены.
- Исправлена доставка перевода в страницы «Карьера», «Матчи», «Гайды» и вложенные кадры, включая кадры с первоначально пустым адресом и временной неготовностью.
- Исправлены наложения вкладок «Рекомендуемые» / «Популярные», шрифт русских кнопок, ширина подписей в «Карьере», метки роста/сезона и служебная роль «Эксперт ACE». Никнеймы и пользовательские названия не меняются.
- Менеджер, переустановка, ярлык и кнопка запуска проверены живьём на Windows 11 через API приложения, без Computer Use. Три цикла установки/запуска; последний запуск подключил перевод автоматически. Проверки: 45/45 runtime, 48/48 activator, 13/13 отказов запуска, 34/34 handshake, 18/18 UI recovery. Чистый публичный экспорт: 45/45 runtime.

Игровые данные перевода сохранены из 0.6.8: 4 201 ресурс, 297 текстовых sidecars / 220 565 известных строк. Трей, службы и постоянные фоновые процессы не добавлены.

Остаются открыты: китайская подпись/логотип/нижний текст ранней загрузки; отдельные надписи внутри картинок, пользовательский контент и видеоматериалы; ранее отмеченные белые области и отдельные футеры. Новый ранний Prime-патч в этот выпуск не входит: его consumer не подтверждён. Игра была закрыта пользователем до главного меню, поэтому достижение меню не заявляется. Живой Windows 10 и неизвестное будущее обновление не проверены. Автоматическое сохранение перевода при обновлении файлов игры не гарантируется; после подготовки нового кэша используйте переустановку.
